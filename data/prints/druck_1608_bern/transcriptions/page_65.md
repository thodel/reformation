Bychtuatter.
JN dinem Namen süsser Herr Jesu: Erwürdigen gün-
stigen wysen Herrn / gester han ich das erst / das Herr
Berchtold jetz gemeldt hat / der Dienstbarkeit halb
oder Diener / wie sy sich Diener nemen / gnügsam verant-
wurt / das thüt ein Künig ouch / ist dennocht ein Künig.
Ist nüt vnzimlich noch vnmöglichs da har bracht / ob schon
einer ist / vnd genennt wirt ein Oberer / vnd Vnderthon zü-
uerglichen / nicht gegen eim : Ein Hertzog in eim Künigrich
mag genempt werden ein Vnderthon : Er ist ouch ein Obe-
rer / züuerglichet dem Künig / so ist er ein Vnderthon : Zü-
uerglichet gegen sinen Vnderthonen lüten / so ist er ein Obe-
rer / vnd wirt genempt ein Houpt / das ist eins.
Vff das ander zeantwurten / bezüg ich / ist mir nicht
möglich / gloub ouch das wenigen möglich ordenlich in das
Houpt zefassen zeuerantwurten / nun sind der gründ vnnd
vrsachen harnach volgend / so vil / das ich die nit wol behal-
ten mag / beger aber daß mir Herr Berchtold die nochmals
eröffne / wil ich darnach aber antwurten.
Berchtoldus.
