452        Die Sibend Schlußred.

Barmhertzigkeit / lehre das vnſer zethuͦn / ſagen wir /
daß alle Werck / die beſchehen Goͤttlicher Gerechtigkeit
gnuͤg zethuͦn / Chriſtum außlaͤren / aber die Gerechtig-
keit deß Glaubens giltet allein: welches Paulus zun
Roͤmern vnd Galathern zum ſtaͤrckſten bezuͤget / das
Ort I. Johannis 5. bewaͤhrt kein Faͤgfeur. So aber hie
zu lang von ſynem Sinn zuͦ reden / ſagen wir kuͤrtzlich /
daß nit folget: Es iſt ein Suͤnd / fuͤr die man nit bitten
ſoll / ſo iſt ein Faͤgfeur. Das Ort Matthei am 12. Die
Suͤnd in heiligen Geiſt werde weder hie noch dort nach-
gelaſſen / ſchluͤßt nit / daß etlich Suͤnd in jener Welt
werden nachgelaſſen / dann es iſt Locus à ſufficienti diviſione,
vermag als vil / als wird nimmermehr nachgelaſſen:
vnd das iſt auch kurtzlich die Suͤnd / von dero Johannes
am vordrigen Ort redt / glych als ſo man ſpricht / Der
hat weder Tag noch Nacht Ruͦh / folget nit / So hat er
etwan Ruͦh / ſonders Tag vnd Nacht ſind die gantze
Außtheilung der Zyten / dann alle Zyt iſt eintweders
Tag oder Nacht. Alſo auch hie nimt Chriſtus fuͤr:
Wird nimmer nachgelaſſen / die gantze Abtheilung der
hieſigen vnd doͤrtigen welt / vnd ſpricht: Sy werde weder
hie noch doͤrt nachgelaſſen / fuͤr nimmer / vnd iſt Periphraſis
ipſius nunquam. Empfehlen vnſere Lehr vnd Verſtand
auch allen Chriſtglaͤubigen / vnd nit der Paͤpſtlichen
Kilchen / zuͦ vrtheilen.
